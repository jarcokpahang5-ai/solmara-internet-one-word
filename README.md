# The Internet in One Word

An entry for make.fun's [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) bounty: describe the whole internet in a single word.

The entry word is **"Procrastibrowsing"** — procrastination + browsing. Everyone opens the internet meaning to do one useful thing and ends up wandering through tabs, videos and threads instead. That is the whole internet in one word.

`main.py` (pure Python 3.13 standard library, deterministic, no network) writes that one word to `/output/entry.txt` when run.
